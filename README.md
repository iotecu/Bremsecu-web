# Bremsecu Web

Website repository for Bremsecu.

## Asset folders

- `public/images/hero/desktop/` — desktop hero images
- `public/images/hero/mobile/` — mobile hero images
- `public/images/product/` — suitcase/product images
- `public/images/app/` — Bremsecu app screenshots and device mockups
- `public/images/methodology/` — measurement methodology visuals, truck/wiring/ECU imagery
- `public/images/partners/` — partner logos and related assets
- `public/images/about/` — team/company/history visuals

Upload the prepared hero images into the desktop/mobile hero folders. Keep filenames simple and consistent, e.g. `hero-01.jpg`, `hero-02.jpg`.
